## 📋 Sobre o Projeto

O **Nexus Data Intelligence** é uma solução **Full-Stack** desenvolvida para prestar serviços a pessoas e empresas interessadas em processamneto de dados. O projeto consiste em uma plataforma institucional dinâmica para uma empresa simulada de consultoria de dados, integrando uma interface rica e responsiva a um sistema robusto de processamento e persistência de informações no Back-End.

O grande diferencial técnico deste projeto é que a captação de potenciais clientes (*leads*) através do formulário não é apenas visual: os dados são processados ativamente via servidor e armazenados de forma estruturada em um banco de dados relacional.

> 🌐 **Acesse o front-end online:** [Nexus Data Intelligence](https://filipesep.github.io/DesafioElos/)

---

## 🚀 Funcionalidades e Fluxo da Aplicação

* **Design Responsivo & UX:** Interface fluida, moderna e totalmente adaptável para dispositivos móveis e desktops.
* **Seções Estratégicas:** Apresentação dinâmica dos pilares da empresa (Arquitetura SQL, Business Intelligence e Processos ETL).
* **Formulário de Captação Dinâmico:** Captura as interações dos usuários e envia as requisições de forma segura.
* **Processamento Back-End:** Script em PHP responsável por receber, validar, higienizar e tratar as requisições enviadas pela interface.
* **Persistência de Dados Relacional:** Armazenamento seguro das informações dos leads em um banco de dados SQL estruturado, simulando o início de um funil de CRM real.
