## 📋 Sobre o Projeto

O **Nexus Data Intelligence** é uma Landing Page institucional moderna e responsiva desenvolvida como solução para o **Desafio Elos**. O objetivo do projeto é simular o ecossistema digital de uma empresa especializada em consultoria de dados, destacando serviços essenciais como Arquitetura SQL, Business Intelligence (Power BI) e Engenharia de Dados (ETL).

A aplicação foi projetada com foco em experiência do usuário (UX), contendo uma interface limpa, navegação fluida, seções institucionais bem definidas e um formulário funcional para captação de potenciais clientes (*leads*).

> 🌐 **Acesse o projeto online:** [Nexus Data Intelligence](https://filipesep.github.io/DesafioElos/)

---

## 🚀 Funcionalidades

* **Design Responsivo:** Adaptado perfeitamente para visualização em desktops, tablets e smartphones.
* **Seção Hero de Alto Impacto:** Apresentação clara da proposta de valor da empresa com chamada para ação (*CTA*).
* **Portfólio de Serviços:** Exibição estruturada das frentes tecnológicas (SQL, BI e ETL) utilizando componentes visuais modernos.
* **Formulário de Captação de Leads:** Validação estruturada para coleta de dados de contato de potenciais clientes.
* **Navegação Inteligente:** Menu fluido que melhora a usabilidade e o direcionamento do usuário dentro da página.

---

## 🛠️ Tecnologias Utilizadas

Para a construção deste projeto, priorizou-se o desenvolvimento nativo (*Vanilla*) para garantir máxima performance, SEO otimizado e código limpo:

* **HTML5:** Estruturação semântica de tags para acessibilidade e melhor indexação em motores de busca.
* **CSS3:** Estilização moderna utilizando conceitos avançados de Layouts Flexíveis (Flexbox e CSS Grid), variáveis de ambiente para paleta de cores e transições suaves.
* **JavaScript (ES6+):** Manipulação dinâmica do DOM para interatividade, controle do menu responsivo e lógica de validação de dados.

---

## 📈 Diferenciais de Arquitetura e Visão de Dados

Embora seja uma aplicação majoritariamente Front-End, o projeto foi concebido sob a ótica de negócios orientados a dados. As seções foram planejadas para representar fluxos reais de grandes corporações:
1. **Modelagem SQL:** Representando a infraestrutura e a fundação sólida dos dados.
2. **Business Intelligence:** A camada de visualização estratégica para tomada de decisão (Power BI).
3. **Processos ETL:** A engenharia por trás do movimento e tratamento massivo de informações.
