# 📊 Nexus Data Intelligence - Landing Page

Este projeto foi desenvolvido como parte do teste técnico para a vaga de **Frontend / Full-Stack Developer** na **Ellos Design**.

A proposta é uma landing page para uma consultoria de análise de dados, focada em conversão de leads e performance.

## 🛠 Tecnologias Utilizadas
- **Frontend:** HTML5, CSS3, Sass (SCSS) e JavaScript (Vanilla).
- **Backend:** PHP 8.x.
- **Banco de Dados:** MySQL.
- **Ícones:** Font Awesome 6.

## 🚀 Como executar o projeto
1. Clone este repositório em sua pasta `htdocs` (se estiver usando XAMPP) ou equivalente.
2. Certifique-se de que o servidor Apache e MySQL estejam rodando.
3. Acesse o **phpMyAdmin** e crie um banco de dados chamado `nexus_data`.
4. Importe o arquivo `banco.sql` (localizado na raiz deste projeto) para criar a tabela de contatos.
5. Acesse no navegador: `http://localhost/seu-diretorio/index.html`.

## 📁 Diferenciais Implementados
- **Full-Stack:** Formulário funcional gravando dados via PDO para maior segurança.
- **Design Moderno:** Utilização de paleta de cores tecnológica e tipografia Inter.
- **Responsividade:** Layout totalmente adaptado para dispositivos móveis (menu hamburguer incluso).
- **Animações:** Aplicação de animações de entrada (FadeInUp) via CSS.
